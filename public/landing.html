Natureza do Projeto: Prova de Conceito (PoC) Portfólio Técnico

Este projeto foi desenvolvido estritamente como projeto de portfólio profissional e prova de conceito técnica. Seu propósito primordial é evidenciar a aplicação prática de engenharia de software moderna, integrando arquitetura de banco de dados relacional, APIs RESTful seguras, mitigação de vulnerabilidades comuns e visualização de telemetria industrial.

O sistema não se destina ao uso em produção industrial real, operando sobre dados derivados do dataset público de referência internacional AI4I 2020 Predictive Maintenance Dataset (Kaggle). As rotinas de autenticação, rate limiting e invalidação de sessão foram construídas para ilustrar padrões robustos de mercado em um ambiente didático e reprodutível.

✓ Fullstack JavaScript ✓ PostgreSQL Relacional ✓ OWASP Top 10 Hardening ✓ Docker Orchestration
Visão Geral & Propósito

O que é o HydroMetrics O&M?

Em plantas de saneamento e tratamento de efluentes, paradas não planejadas em equipamentos críticos causam prejuízos operacionais severos. O HydroMetrics transforma dados brutos de sensores em indicadores de ação preventiva.

01

Monitoramento de Ativos

Acompanhamento contínuo de bombas de captação e recalque, motores de aeração e compressores industriais com categorização por grau de criticidade.

  • Bombas Centrífugas de Alta Vazão
  • Motores de Tratamento Biológico
  • Compressores de Aeração Contínua
02

Análise de Tendência e Eficiência

Cálculo automatizado de KPIs operacionais e correlação entre temperatura do ar, temperatura de processo, torque e velocidade de rotação (RPM).

  • Agregações SQL com GROUP BY temporal
  • Detecção precoce de desgaste (Tool Wear)
  • Taxa de falhas operacionais em tempo real
03

Segurança Defensiva Incorporada

Desenvolvido sob o paradigma de Security by Design, com auditoria de vulnerabilidades mitigadas e comprovadas por suíte de testes automatizados.

  • JWT via Cookies HttpOnly e SameSite
  • Proteção contra enumeração de usuários
  • Rate limiting e Content Security Policy

Engenharia de Dados & Software

Fluxo e Camadas da Aplicação

Arquitetura desacoplada em três camadas principais, orquestrada via contêineres Docker para portabilidade e isolamento.

1. Dados Brutos 📁

AI4I 2020 Dataset

ETL via streaming de CSV com conversão tipada e injeção em lotes de telemetria física real.

2. Persistência 🐘

PostgreSQL 15

Tabelas normalizadas, integridade referencial com ON DELETE CASCADE e índices otimizados por data e status.

3. Backend & Segurança ⚡

Node.js Express API

Camada de serviços com Helmet CSP, Rate Limiting, autenticação JWT HttpOnly e queries 100% parametrizadas.

4. Apresentação 📈

Frontend Vanilla & Charts

Aplicação cliente ágil sem dependências pesadas, utilizando Chart.js para telemetria interativa.

Segurança Defensiva

Mitigações de Vulnerabilidade Validadas

Como diferencial técnico para o portfólio, este projeto passou por auditoria de segurança prática com validação das seguintes defesas:

Vulnerabilidade / Vetor Classificação OWASP Implementação Técnica Status de Validação
Revogação de Sessão JWT A01:2021 — Broken Access Control Mecanismo de blacklist em memória com expiração automática que invalida tokens após o logout. ✓ Mitigado & Testado
Bypass de Rate Limit por IP A04:2021 — Insecure Design Configuração de trust proxy 1 para obtenção verídica do IP cliente atrás de proxies reversos. ✓ Mitigado
Enumeração de Usuários A07:2021 — Identification & Auth Status uniforme 202 Accepted tanto para e-mails novos quanto já existentes, eliminando temporização assimétrica. ✓ Mitigado & Testado
Injeção de SQL (SQLi) A03:2021 — Injection Todas as consultas com queries preparadas e parâmetros numerados ($1, $2) no driver pg. ✓ Mitigado & Testado
Cross-Site Scripting (XSS) A03:2021 — Injection Cookies de autenticação restritos via flags HttpOnly, SameSite=Strict e cabeçalhos CSP via Helmet. ✓ Mitigado
Princípio do Menor Privilégio A05:2021 — Security Misconfiguration Criação do usuário de banco ast_app_user com permissões estritas apenas de DML, sem privilégios de superusuário. ✓ Implementado
